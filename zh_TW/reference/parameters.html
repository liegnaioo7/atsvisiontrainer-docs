全架構參數核對表¶

以下預設值和數值範圍由當前實際介面讀取；功能說明與軟體適配程式碼逐項核對。切換預設、裝置或高階 YAML 後，實際生效值以實驗中的最終配置為準。

“沿用配置”的佔位值不是引擎訓練值；空路徑表示使用者尚未選擇。現代 workers 與經典 Windows 的 workers 實現不同。

現代目標偵測¶

參數 介面預設/傳遞值 可輸入數值範圍 實際含義
imgsz 640 見說明（文字、選項或路徑） 現代架構的單個輸入尺寸。分類按其前處理裁剪，偵測/分割/旋轉框按引擎規則縮放及填充；不是直接設定任意高寬。
epochs 1000 1～10000 最大訓練輪數；現代架構可能因早停或手動停止提前結束。
patience 100 0～1000 現代架構連續無驗證指標改善的早停耐心輪數；0 關閉早停。
workers 8 0～64 現代架構是資料載入程序數；經典架構在 Windows 上大於 0 使用執行緒並行讀圖及前處理，0 使用原有載入方式。
batch 16 1～512 每批處理圖片數；異常偵測是特徵提取批大小。顯示記憶體不足時減小。
device 未選擇 / 沿用配置 見說明（文字、選項或路徑） 選擇計算裝置。現代 auto 由引擎選擇，gpu 使用第 0 張；經典及異常偵測 GPU 使用介面指定的一張卡，失敗不會靜默切回 CPU。
seed 42 0～99999 隨機種子；相同種子不保證跨裝置、跨環境的結果完全一致。
amp true 見說明（文字、選項或路徑） 混合精度。現代介面 True/False；經典介面沿用配置/關閉/開啟，僅 GPU 可顯式開啟。CPU 不啟用經典 AMP。
optimizer "auto" 見說明（文字、選項或路徑） 選擇最佳化器。現代 auto 會覆蓋手動初始學習率、動量，並將熱身偏置學習率設為 0；經典 config 沿用 YAML。
momentum 0.937 0.0～1.0 SGD 類最佳化器的動量；Adam 類通常作為 beta1。現代 auto 可能覆蓋此項。
weight_decay 0.0005 0.0～0.1 權重衰減係數；經典負值預設表示沿用配置，不向引擎傳遞負衰減。
warmup_epochs 3.0 0.0～50.0 預熱輪數。現代支援小數；經典僅在選擇餘弦策略時可調，必須小於總輪數。
warmup_momentum 0.8 0.0～1.0 現代偵測/分割/旋轉框預熱階段的初始動量。
warmup_bias_lr 0.1 0.0～1.0 現代偵測/分割/旋轉框預熱階段的偏置初始學習率；auto 最佳化器會將其設為 0。
degrees 0.0 0.0～180.0 訓練時隨機旋轉的最大絕對角度；0 關閉。分類使用本軟體的顯式隨機旋轉適配。
flipud 0.0 0.0～1.0 訓練時上下翻轉的機率。
fliplr 0.5 0.0～1.0 訓練時左右翻轉的機率。
translate 0.1 0.0～1.0 訓練時平移幅度，相對影像尺寸，不是像素數量。
scale 0.0 0.0～1.0 訓練時隨機縮放幅度；不是目標輸入尺寸或推論放大倍數。
mosaic 0.0 0.0～1.0 訓練時馬賽克拼圖機率；仍遵循引擎的末期關閉規則。
box 7.5 0.0～20.0 框定位損失權重，不是偵測閾值。
cls 0.5 0.0～20.0 目標類別損失權重，不是類別數。
dfl 1.5 0.0～20.0 分佈焦點損失（DFL）權重；是否產生該損失由當前模型結構決定。
copy_paste 0.1 0.0～1.0 偵測按機率複製同圖目標到不重疊位置；分割為原生遮罩複製貼上比例。沒有安全位置會跳過；OBB 無此控制項。
erasing 0.4 0.0～1.0 偵測和分割只擦除目標框之外的背景，保留目標和標註；OBB 無此控制項。
model_path "ats-m.pt" 見說明（文字、選項或路徑） 選擇與任務匹配的預置權重。實際檔案由軟體隨附目錄定位。
dataset_path 未選擇 / 沿用配置 見說明（文字、選項或路徑） 選擇當前任務的資料集；格式與訓練/驗證規則見對應架構章節。

經典目標偵測 2.7.0¶

output "<軟體目錄>\\runs\\classic_det" 見說明（文字、選項或路徑） 經典訓練輸出根目錄；每次新建獨立時間戳實驗子目錄。
