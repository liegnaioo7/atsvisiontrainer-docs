模型推理与自动导出¶

主推理页面支持范围¶

“模型推理验证”支持四种现代任务，以及经典目标检测和经典分类。异常检测请使用异常检测自己的推理页。

架构 输入权重 还需要什么
现代架构 .pt 或 .onnx 匹配的任务类型；ONNX 尤其需要选对任务
经典检测/分类 .pdparams 与模型匹配的训练 YAML，可从训练实验导入
异常检测自己的页面 model.patchcore.pt 同页的图片来源、设备及阈值倍率

经典训练实验导入会优先选择有效的最终配置快照和实际检查点，不用 YAML 中的预训练 URL 冒充已经训练好的模型。必要时可指定类别 TXT；经典权重形状不匹配会报错，不允许悄悄使用随机参数。

任务类型、阈值与设备¶

现代任务包括分类、目标检测、实例分割和旋转框检测。切换为经典架构后任务类型由所选架构固定。

置信度阈值界面默认为 0.3，可输入 0.01～1.0。检测类推理按阈值保留结果；经典分类返回达到阈值的最多前 5 个类别。现代分类的原生结果处理不按这个 conf 控件过滤分类概率，不能把该控件解释为现代分类的 OK/NG 判定规则。

现代 PT 支持按设备选项执行；当前软件将现代 ONNX 强制回退 CPU 推理，即使选了 GPU，也会在日志中提示，不承诺 ONNX GPU 推理。经典推理可在 CPU 或所选的一张 NVIDIA GPU 执行。

预处理¶

软件生成的现代分类 PT/ONNX 内含中心裁剪预处理元数据，软件推理会读取；只有 ONNX 外部推理程序不会因为旁边存在 JSON 就自动应用预处理，仍需部署方正确实现。

经典分类从配置的 Infer 预处理和类别映射读取；经典检测使用匹配的 TestReader。任意外部权重若缺少对应训练配置，仅靠文件扩展名不能还原正确预处理。

输出目录¶

现代推理不指定输出目录时由模型任务决定默认位置；显式指定目录时直接保存到该目录，允许复用，注意同名结果可能被覆盖。

经典和异常检测推理在输出根目录下新建独立实验目录，保存可视化及结构化结果。实际输出路径以完成日志为准。

训练自动导出¶

训练架构 成功后导出
四种现代架构 ONNX；检测/分割/OBB 另有 infer_cfg.yml，分类另有 Label.txt 与预处理信息
经典检测 model.pdmodel、model.pdiparams、参数信息文件及 infer_cfg.yml
经典分类 推理模型、参数、ImageSize.txt、部署 YAML、类别清单
异常检测 自包含 model.patchcore.pt，使用异常检测推理流程

现代 ONNX 默认不简化图，不自动安装 onnxslim；OBB 不内嵌 NMS。经典导出在本次独立进程内使用 CPU，训练可仍为 GPU。软件在训练完成后可能继续显示“正在导出”，要等导出结果明确后再拿模型部署。

训练完成不代表导出一定完成。经典导出失败会保留训练权重和完整实验文件，可查看 export.json 与原始日志；不要删除整个实验来“重试导出”。
