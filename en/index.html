ATSVisionTrainer Help Center¶

This manual reflects the current UI and parameter adapters, covering four modern architectures, two classic architectures and anomaly detection. Choose the task page first, then prepare a matching dataset; configurations from different architectures are not interchangeable.

What you want to do Read more

Read this online manual directly in your browser without installing or starting the application. Help inside the application continues to provide the bundled offline version.

The manual is available in Simplified Chinese, English, Italian, Japanese and Traditional Chinese. Switch languages using the toolbar at the top of the page.

About defaults

Defaults in this manual are the current initial UI values, not assumed values for every model YAML. When a classic architecture uses its configuration, the final training values come from the selected model configuration. Use each experiment's effective configuration and raw log to verify actual behavior.
