Быстрый старт¶

  1. Выберите для задачи современные архитектуры, классические архитектуры или обнаружение аномалий. Используйте классификацию для идентификации классов, обнаружение для обычных коробок, сегментацию экземпляров для масок и ориентированное обнаружение для коробок с ориентацией.
  2. Классическое обнаружение и классификация требуют одной папки набора данных; современные задачи требуют своего собственного формата ярлыка.
  3. Выберите модель, устройство и параметры вывода. Классические и аномальные задачи используют собственные независимые среды. Можно выбрать один из нескольких графических процессоров NVIDIA; текущая реализация Windows не поддерживает совместное обучение нескольких графических процессоров одной классической модели.
  4. Используйте небольшую партию и несколько эпох для проверки путей, меток, памяти GPU и выходов перед полным обучением. Эта проверка рабочего процесса не оценивает окончательную точность.
  5. После запуска используйте журналы Console для графиков и необработанной продукции. Графики показывают тенденции; журналы необработанных данных показывают инициализацию, валидацию, экспорт и детали ошибок.
  6. После успешного обучения проверьте автоматически экспортируемую модель. Классическое обучение и экспорт являются отдельными этапами; экспортный сбой сохраняет сэкономленные тренировочные веса.
  7. Откройте эксперимент из истории обучения или выберите модель для проверки выводов. Вывод аномалий находится на своей странице.

Задание делает снимок параметра при запуске. Редактирование элементов управления после этого не меняет выполняемую задачу; вносит изменения перед началом следующей.

Закрытие заявки требует подтверждения и по умолчанию отменяется. Подтверждение выхода во время выполнения задачи прекращает его. Подождите, пока завершится очистка учебного файла перед выходом.

Три типа сред выполнения¶

Архитектура Методика обучения Выбор устройства
Четыре современные архитектуры Современный тренировочный двигатель Auto / gpu / cpu; gpu позволяет выбрать один доступный графический процессор
Две классические архитектуры Независимая классическая среда CPU или любой другой выбранный NVIDIA GPU
обнаружение аномалий Независимая среда обнаружения аномалий CPU или любой другой выбранный NVIDIA GPU

Явно выбранный графический процессор не бесшумно возвращается к процессору, когда он недоступен. Для современных, классических и аномальных задач проверьте журналы, выбранное устройство и окружение. В автоматическом режиме двигатель по-прежнему выбирает устройство.

Обновления программы¶

Откройте «Обновления программы» в боковом меню и укажите HTTPS-адрес списка обновлений от издателя. Проверьте обновления, прочитайте изменения, затем загрузите, проверьте и установите пакет. Для автономных компьютеров доступен импорт официального файла .atsupdate. Устанавливайте после завершения обучения, инференса, очереди и отправки отзывов. В среде разработки доступна проверка; установка выполняется в полной сборке.

Сохраните package-manifest.json и Updater.exe в каталоге программы: они нужны для проверки версии и установки. Загрузки и резервные копии можно размещать на другом диске. При сбое или прерывании проверьте журнал; при необходимости закройте другие экземпляры и запустите Updater.exe для восстановления.
