全架构参数核对表¶

以下默认值和数值范围由当前实际界面读取；功能说明与软件适配代码逐项核对。切换预设、设备或高级 YAML 后，实际生效值以实验中的最终配置为准。

“沿用配置”的占位值不是引擎训练值；空路径表示用户尚未选择。现代 workers 与经典 Windows 的 workers 实现不同。

现代目标检测¶

参数 界面默认/传递值 可输入数值范围 实际含义
imgsz 640 见说明（文本、选项或路径） 现代架构的单个输入尺寸。分类按其预处理裁剪，检测/分割/旋转框按引擎规则缩放及填充；不是直接设置任意高宽。
epochs 1000 1～10000 最大训练轮数；现代架构可能因早停或手动停止提前结束。
patience 100 0～1000 现代架构连续无验证指标改善的早停耐心轮数；0 关闭早停。
workers 8 0～64 现代架构是数据加载进程数；经典架构在 Windows 上大于 0 使用线程并行读图及预处理，0 使用原有加载方式。
batch 16 1～512 每批处理图片数；异常检测是特征提取批大小。显存不足时减小。
device 未选择 / 沿用配置 见说明（文本、选项或路径） 选择计算设备。现代 auto 由引擎选择，gpu 使用第 0 张；经典及异常检测 GPU 使用界面指定的一张卡，失败不会静默切回 CPU。
seed 42 0～99999 随机种子；相同种子不保证跨设备、跨环境的结果完全一致。
amp true 见说明（文本、选项或路径） 混合精度。现代界面 True/False；经典界面沿用配置/关闭/开启，仅 GPU 可显式开启。CPU 不启用经典 AMP。
optimizer "auto" 见说明（文本、选项或路径） 选择优化器。现代 auto 会覆盖手动初始学习率、动量，并将热身偏置学习率设为 0；经典 config 沿用 YAML。
momentum 0.937 0.0～1.0 SGD 类优化器的动量；Adam 类通常作为 beta1。现代 auto 可能覆盖此项。
weight_decay 0.0005 0.0～0.1 权重衰减系数；经典负值默认表示沿用配置，不向引擎传递负衰减。
warmup_epochs 3.0 0.0～50.0 预热轮数。现代支持小数；经典仅在选择余弦策略时可调，必须小于总轮数。
warmup_momentum 0.8 0.0～1.0 现代检测/分割/旋转框预热阶段的初始动量。
warmup_bias_lr 0.1 0.0～1.0 现代检测/分割/旋转框预热阶段的偏置初始学习率；auto 优化器会将其设为 0。
degrees 0.0 0.0～180.0 训练时随机旋转的最大绝对角度；0 关闭。分类使用本软件的显式随机旋转适配。
flipud 0.0 0.0～1.0 训练时上下翻转的概率。
fliplr 0.5 0.0～1.0 训练时左右翻转的概率。
translate 0.1 0.0～1.0 训练时平移幅度，相对图像尺寸，不是像素数量。
scale 0.0 0.0～1.0 训练时随机缩放幅度；不是目标输入尺寸或推理放大倍数。
mosaic 0.0 0.0～1.0 训练时马赛克拼图概率；仍遵循引擎的末期关闭规则。
box 7.5 0.0～20.0 框定位损失权重，不是检测阈值。
cls 0.5 0.0～20.0 目标类别损失权重，不是类别数。
dfl 1.5 0.0～20.0 分布焦点损失（DFL）权重；是否产生该损失由当前模型结构决定。
copy_paste 0.1 0.0～1.0 检测按概率复制同图目标到不重叠位置；分割为原生掩膜复制粘贴比例。没有安全位置会跳过；OBB 无此控件。
erasing 0.4 0.0～1.0 检测和分割只擦除目标框之外的背景，保留目标和标注；OBB 无此控件。
model_path "ats-m.pt" 见说明（文本、选项或路径） 选择与任务匹配的预置权重。实际文件由软件随附目录定位。
dataset_path 未选择 / 沿用配置 见说明（文本、选项或路径） 选择当前任务的数据集；格式与训练/验证规则见对应架构章节。

momentum 0.9 0.0～1.0 SGD 类优化器的动量；Adam 类通常作为 beta1。现代 auto 可能覆盖此项。
weight_decay 0.05 0.0～0.5 权重衰减系数；经典负值默认表示沿用配置，不向引擎传递负衰减。

degrees 180.0 0.0～180.0 训练时随机旋转的最大绝对角度；0 关闭。分类使用本软件的显式随机旋转适配。
flipud 0.5 0.0～1.0 训练时上下翻转的概率。
fliplr 0.5 0.0～1.0 训练时左右翻转的概率。
crop_fraction 1.0 0.1～1.0 现代分类短边保留比例；小于 1 时先将短边放大至 imgsz/比例再中心裁剪。训练、验证、软件推理保持这一中心区域规则；训练仍叠加随机增强。
model_path "ats-m-cls.pt" 见说明（文本、选项或路径） 选择与任务匹配的预置权重。实际文件由软件随附目录定位。
dataset_path 未选择 / 沿用配置 见说明（文本、选项或路径） 选择当前任务的数据集；格式与训练/验证规则见对应架构章节。

经典目标检测 2.7.0¶

参数 界面默认/传递值 可输入数值范围 实际含义
python "<软件目录>\\Paddle\\runtime-cpu\\python.exe" 见说明（文本、选项或路径） 经典架构独立运行环境的解释器；由 CPU/GPU 选择自动定位，也可手动指定兼容环境。
config "<软件目录>\\Paddle\\PaddleDetection-2.7.0\\configs\\ppyoloe\\ppyoloe_plus_crn_s_80e_coco.yml" 见说明（文本、选项或路径） 参考 YAML；s/m/l/x/sod 为经典检测预设，分类为实际预置配置名称。
output "<软件目录>\\runs\\classic_det" 见说明（文本、选项或路径） 经典训练输出根目录；每次新建独立时间戳实验子目录。
epochs 100 1～100000 最大训练轮数；现代架构可能因早停或手动停止提前结束。
batch 4 1～4096 每批处理图片数；异常检测是特征提取批大小。显存不足时减小。
seed 42 0～99999 随机种子；相同种子不保证跨设备、跨环境的结果完全一致。
device "cpu" 见说明（文本、选项或路径） 选择计算设备。现代 auto 由引擎选择，gpu 使用第 0 张；经典及异常检测 GPU 使用界面指定的一张卡，失败不会静默切回 CPU。
weight_mode "config" 见说明（文本、选项或路径） config 沿用配置中的预训练设置；local 使用本地 .pdparams；random 随机初始化。config 可能联网下载权重。
weights 未选择 / 沿用配置 见说明（文本、选项或路径） 仅在选择本地预训练权重时使用的 .pdparams 文件。
dataset.mode "coco" 见说明（文本、选项或路径） 经典检测默认 coco，分类默认 classification；config 表示沿用 YAML 中的数据设置。
dataset.root 未选择 / 沿用配置 见说明（文本、选项或路径） 经典数据集根目录。只选一个文件夹，识别规则见数据集章节。
dataset.evaluate_on_train false 见说明（文本、选项或路径） 默认关闭；开启后用全部训练图片和标注替代独立验证集执行评估，指标仅反映训练集拟合情况。
training_options.image_size_mode "config" 见说明（文本、选项或路径） 经典检测 config 沿用尺寸，fixed 统一训练/验证/导出尺寸，eval 只改验证/测试/导出尺寸。
