Обнаружение аномалий ATSAnomaly¶

Подходит для построения банка памяти только из нормальных ОК-изображений, затем для идентификации новых изображений, отклоняющихся от нормального распределения.Текущая реализация использует метод PatchCore, без многоэпохальной градиентной тренировки, как в обычной классификации.

Учебные и калибровочные данные¶

Учебные и независимые калибровочные каталоги должны содержать только ОК-изображения. Если калибровка пустая, изображения дублируются по содержанию и примерно 20% удерживается с помощью фиксированного случайного семени 42; требуется по меньшей мере 3 отдельные изображения. Калибровочные изображения не поступают в банк памяти; дубликаты контента между обучением и независимой калибровкой вызывают ошибку.

Пороги, оцененные только по изображениям ОК, не могут установить отзыв дефектов, ложноположительную скорость или точность производства. Проверить эффективность бизнеса с использованием независимых образцов ОК/NG.

ROI, тайлинг и калибровка¶

Нажмите «Выбрать ROI на изображении» и откройте эталонное изображение с тем же ракурсом, что и обучающие данные. Нарисуйте прямоугольник перетаскиванием, затем изменяйте его размер за края или углы. Проценты и область на изображении синхронизируются. Затемнённые части находятся вне области контроля. «Всё изображение» восстанавливает полный кадр. «Применить ROI» включает ROI и переносит область на страницу обучения; отмена сохраняет прежние настройки. Эталонное изображение служит для выбора области; обучающие изображения определяются папкой обучения.

ROI по умолчанию отключена. Левая, верхняя, правая и нижняя границы задаются в процентах исходных размеров, по умолчанию 0, 0, 100, 100. Сначала вырезается ROI, затем выполняется тайлинг. Тайлинг по умолчанию отключён; при включении размер тайла по умолчанию 512 пикселей, перекрытие 0.25. Каждый тайл масштабируется до входного размера модели. Дополнительные крайние тайлы обеспечивают покрытие; малые области обрабатываются в фактическом размере. В перекрытиях выбирается максимальный отклик. Карты и маски возвращаются в исходные координаты. Наложение вне ROI сохраняет исходное изображение, а доля аномальной площади считается только внутри ROI.

Число соседей по умолчанию 9, диапазон 1–32, ограничено размером банка. Квантиль калибровки по умолчанию 0.99, диапазон 0.9–1; коэффициент запаса 1.05, диапазон 1–3. Пороги изображения и пикселей отдельно оцениваются по оценкам изображений OK и пикам пикселей, как произведение квантиля и коэффициента. После изменения этих параметров перестройте модель и сравните пропуски и ложные срабатывания на независимых данных OK/NG.

ROI, тайлинг и число соседей сохраняются в модели и автоматически читаются при инференсе и оценке. Новые модели имеют формат v2; поддерживается загрузка существующих моделей v1. Старые модели обрабатывают полное изображение. Тайлинг увеличивает время извлечения признаков и инференса; размер банка ограничен числом кандидатов, долей отбора и пределом банка.

Порог и инференс¶

На вкладке инференса аномалий выберите модель из истории обучения или укажите локальный файл модели. В списке отображаются только записи обнаружения аномалий, файлы моделей которых существуют. Чтобы добавить старые эксперименты, укажите каталог на странице истории обучения, затем обновите список моделей. После инференса в поле результатов последнего инференса отображается фактический каталог сохранения. Его можно открыть соседней кнопкой. Для каждого запуска создаётся отдельный подкаталог с меткой времени внутри каталога результатов.

Модель сохранена как model.patchcore.pt. Используйте проверку вывода аномалии на этой странице для вывода, с одним изображением или папкой изображения.

Оценки аномалии являются расстояниями признаков, а не вероятностями и не обязаны лежать в пределах 0–1. Множители изображения и маски по умолчанию равны 1: меньше 1 повышает чувствительность, больше 1 смягчает порог. Оценка не ниже порога изображения означает NG. Множитель пикселей регулирует маску независимо; выбранный при оценке множитель применяется только к решению по изображению.

Результаты включают в себя OK/NG, оценки аномалий, тепловые карты, наложения, маски, необработанные карты оценок и JSON/CSV. Каталог выходных данных не должен находиться внутри каталога входных изображений, предотвращая повторный ввод полученных результатов.

Этот формат модели не является общим ONNX, обычной классификацией PT или классической моделью вывода; не выберите его на главной странице валидации вывода модели. CPU и одно исполнение графического процессора NVIDIA используют независимую среду обнаружения аномалий.

Тестовая оценка OK/NG¶

Откройте оценку OK/NG, выберите модель из истории или локальный файл и укажите независимые тестовые папки OK и NG. Обе должны содержать изображения и не должны быть вложены друг в друга. Подкаталоги читаются рекурсивно. Тестовые изображения не должны использоваться для построения модели или калибровки порога. Одинаковое содержимое нельзя помечать одновременно как OK и NG.

По умолчанию множители задаются от 0.5 до 1.5 с шагом 0.1. Значения получаются прибавлением шага к начальному значению; конец диапазона автоматически не добавляется. Можно сравнить до 201 множителя. Оценка каждого изображения вычисляется один раз. Фактический порог равен исходному порогу изображения модели, умноженному на множитель; оценка не ниже порога означает NG. Оценка помогает выбрать множитель инференса и не перезаписывает файл модели.

NG — положительный класс. Пропуск дефекта — NG, распознанное как OK; ложное срабатывание — OK, распознанное как NG. Полнота NG равна TP / (TP + FN), доля ложных срабатываний на OK — FP / (FP + TN), точность NG — TP / (TP + FP). Если ни одно изображение не предсказано как NG, точность отображается как «—». F1 — гармоническое среднее точности и полноты. Оценка выполняется на уровне изображений, без измерения точности попиксельной сегментации.

Каталог результатов содержит evaluation.json, таблицу сравнения threshold_comparison.csv и оценки изображений evaluation_scores.csv. В последней записаны истинная метка OK/NG, оценка аномалии и решение при исходном множителе 1. Выберите строку сравнения и примените множитель для инференса с той же моделью. После смены модели выполните оценку заново. Выбранный порог следует проверить на другом независимом приёмочном наборе данных по пропускам дефектов и ложным срабатываниям.

Полный список диапазонов приведён в таблице параметров обнаружения аномалий.
