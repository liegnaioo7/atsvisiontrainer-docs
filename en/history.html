Training history and disk cleanup¶

Training history lists four modern training tasks, two classic tasks and anomaly model building. Ordinary inference and runtime checks are excluded.

New training runs automatically register their actual experiment paths. Common results locations are scanned by default; for older results elsewhere, click Add history directory and select the experiment folder or its parent. This registers the location without moving or copying training files.

The list shows name, architecture, time, status, size and path, with architecture filters and text search. Select Open experiment folder or double-click a row. Hover to read truncated content.

Older modern records without clear completion information show Status unknown, not training failure. Records with a known running state whose owning application has exited may show Run interrupted. Ordinary weight folders without native experiment metadata are not automatically treated as training experiments.

What deletion does¶

Delete record and training files removes the entire experiment folder, including checkpoints, exported models, logs and charts. Confirmation shows the full path and size and defaults to cancel. Deletion is irreversible. If the folder is already gone, only the index entry is removed.

Cleanup is blocked while training, export or inference is running. During cleanup, new tasks cannot start and exit must wait for completion. Protective checks cover the program directory, runtime environments, datasets referenced by configurations, directory links and nested experiments.

Files in use or insufficient permissions can cause partial cleanup failures; the record remains and an error is shown. A failure does not make already deleted files recoverable. Before proceeding, ensure models requiring long-term retention have independent copies.

Space usage is the logical size of readable files and may differ from the bytes actually freed by the file system. The history index is stored in the current user's local application data and need not move with the installation directory.
