模型推論與自動匯出¶

主推論頁面支援範圍¶

“模型推論驗證”支援四種現代任務，以及經典目標偵測和經典分類。異常偵測請使用異常偵測自己的推論頁。

架構 輸入權重 還需要什麼
現代架構 .pt 或 .onnx 匹配的任務型別；ONNX 尤其需要選對任務
經典偵測/分類 .pdparams 與模型匹配的訓練 YAML，可從訓練實驗匯入
異常偵測自己的頁面 model.patchcore.pt 同頁的圖片來源、裝置及閾值倍率

經典訓練實驗匯入會優先選擇有效的最終配置快照和實際檢查點，不用 YAML 中的預訓練 URL 冒充已經訓練好的模型。必要時可指定類別 TXT；經典權重形狀不匹配會報錯，不允許悄悄使用隨機參數。

任務型別、閾值與裝置¶

現代任務包括分類、目標偵測、實例分割和旋轉框偵測。切換為經典架構後任務型別由所選架構固定。

置信度閾值介面預設為 0.3，可輸入 0.01～1.0。偵測類推論按閾值保留結果；經典分類返回達到閾值的最多前 5 個類別。現代分類的原生結果處理不按這個 conf 控制項過濾分類機率，不能把該控制項解釋為現代分類的 OK/NG 判定規則。

現代 PT 支援按裝置選項執行；當前軟體將現代 ONNX 強制回退 CPU 推論，即使選了 GPU，也會在日誌中提示，不承諾 ONNX GPU 推論。經典推論可在 CPU 或所選的一張 NVIDIA GPU 執行。

前處理¶

軟體生成的現代分類 PT/ONNX 內含中心裁剪前處理後設資料，軟體推論會讀取；只有 ONNX 外部推論程式不會因為旁邊存在 JSON 就自動應用前處理，仍需部署方正確實現。

經典分類從配置的 Infer 前處理和類別對映讀取；經典偵測使用匹配的 TestReader。任意外部權重若缺少對應訓練配置，僅靠副檔名不能還原正確前處理。

輸出目錄¶

現代推論不指定輸出目錄時由模型任務決定預設位置；顯式指定目錄時直接儲存到該目錄，允許複用，注意同名結果可能被覆蓋。

經典和異常偵測推論在輸出根目錄下新建獨立實驗目錄，儲存視覺化及結構化結果。實際輸出路徑以完成日誌為準。

訓練自動匯出¶

訓練架構 成功後匯出
四種現代架構 ONNX；偵測/分割/OBB 另有 infer_cfg.yml，分類另有 Label.txt 與前處理資訊
經典偵測 model.pdmodel、model.pdiparams、參數資訊檔案及 infer_cfg.yml
經典分類 推論模型、參數、ImageSize.txt、部署 YAML、類別清單
異常偵測 自包含 model.patchcore.pt，使用異常偵測推論流程

現代 ONNX 預設不簡化圖，不自動安裝 onnxslim；OBB 不內嵌 NMS。經典匯出在本次獨立程序內使用 CPU，訓練可仍為 GPU。軟體在訓練完成後可能繼續顯示“正在匯出”，要等匯出結果明確後再拿模型部署。

訓練完成不代表匯出一定完成。經典匯出失敗會保留訓練權重和完整實驗檔案，可檢視 export.json 與原始日誌；不要刪除整個實驗來“重試匯出”。
