クイックスタート¶

  1. タスクに応じてモダン構成、クラシック構成、異常検出を選択します。クラスの判定には分類、通常のボックスには物体検出、マスクにはインスタンスセグメンテーション、向きのあるボックスには回転物体検出を使用します。
  2. 対応する形式のデータセットを準備します。クラシック物体検出・分類はデータセットフォルダーを選択し、モダンは各タスクのラベル形式を使用します。
  3. モデル、デバイス、出力関連の設定を選択します。クラシックと異常検出はそれぞれ独立した環境を使用します。複数の NVIDIA GPU から一つを選択できますが、現在の Windows 方式では同一のクラシックモデルを複数 GPU で共同学習することはできません。
  4. 本格的な学習の前に、小さなバッチと少ないエポックでパス、ラベル、GPU メモリ、出力を確認してください。この動作確認は最終精度の評価ではありません。
  5. 開始後はコンソールでグラフと元のログを確認します。グラフは傾向、ログは初期化・検証・エクスポート・エラーの詳細に使用します。
  6. 学習成功後は自動エクスポートしたモデルを確認してください。クラシックの学習完了とエクスポート完了は別の段階であり、エクスポートに失敗しても保存済みの学習重みは保持します。
  7. 学習履歴から実験を開くか、モデルを選んで推論検証を行います。異常検出の推論は専用ページにあります。

開始時にパラメーターを取得します。開始後に画面を変更しても実行中のタスクには反映されません。次の開始前に設定してください。

終了時は確認を表示し、既定はキャンセルです。タスク実行中に終了を確定するとタスクを停止します。学習ファイルの削除中は完了するまで終了を待ってください。

3 系統の実行環境¶

構成 学習方法 デバイスの選択
4 種類のモダンアーキテクチャ モダン学習エンジン auto / gpu / cpu。gpu は GPU 0 を使用
2 種類のクラシックアーキテクチャ 独立したクラシック環境 CPU または選択した 1 台の NVIDIA GPU
異常検出 独立した異常検出環境 CPU または選択した 1 台の NVIDIA GPU

GPU を明示的に選択した後の失敗を、CPU への自動切り替えと解釈しないでください。クラシックと異常検出では GPU が使用できない場合にエラーを表示します。ログと環境を確認してください。
