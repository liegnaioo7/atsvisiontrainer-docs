全アーキテクチャのパラメーター一覧¶

以下の既定値と数値範囲は現在の画面から取得し、説明はソフトウェアの適用処理と照合しています。プリセット、デバイス、高度な YAML の変更後は、実験の最終設定が実際の学習値を決定します。

「設定を継承」のプレースホルダー値はエンジンの学習値ではありません。空のパスは未選択を表します。モダンの workers と Windows のクラシック workers は実装が異なります。

モダン物体検出¶

パラメーター 画面の既定値・渡される値 入力可能な数値範囲 実際の意味
imgsz 640 説明を参照（テキスト・選択肢・パス） モダン構成の単一入力サイズです。分類は前処理規則に従ってクロップし、検出・セグメンテーション・回転検出はエンジン規則に従って拡縮・パディングします。任意の高さと幅を直接設定するものではありません。
epochs 1000 1～10000 学習の最大エポック数です。モダン構成では早期終了や手動停止によって、それ以前に終了する場合があります。
patience 100 0～1000 モダン構成の早期終了の待機エポック数です。検証指標が連続して改善しない回数を指定し、0 で早期終了を無効にします。
workers 8 0～64 モダン構成ではデータ読み込みプロセス数です。クラシック構成の Windows 版では、0 より大きい値で画像読み込みと前処理をスレッド並列化し、0 では元の読み込み方法を使用します。
batch 16 1～512 バッチあたりの処理画像数です。異常検出では特徴量抽出のバッチサイズを指します。GPU メモリーが不足する場合は小さくしてください。
device 未選択 / 設定を継承 説明を参照（テキスト・選択肢・パス） 計算デバイスを選択します。モダンの auto はエンジンが選び、gpu は 0 番を使用します。クラシックと異常検出の GPU は画面で指定したカードを使用し、失敗時に黙って CPU へ切り替えることはありません。
seed 42 0～99999 乱数シードです。同じシードでも、異なるデバイスや環境で完全に同じ結果になる保証はありません。
amp true 説明を参照（テキスト・選択肢・パス） 混合精度です。モダン画面では True/False、クラシック画面では設定を使用／無効／有効を選択します。明示的な有効化は GPU のみです。CPU ではクラシック AMP を有効にしません。
optimizer "auto" 説明を参照（テキスト・選択肢・パス） オプティマイザーを選択します。モダンの auto は手動の初期学習率とモメンタムを上書きし、ウォームアップのバイアス学習率を 0 に設定します。クラシックの config は YAML を使用します。
momentum 0.937 0.0～1.0 SGD 系ではモーメンタム、Adam 系では通常 beta1 に対応します。モダンの auto で上書きされる場合があります。
weight_decay 0.0005 0.0～0.1 重み減衰係数です。クラシック構成の既定の負値は設定の使用を意味し、負の減衰係数をエンジンに渡すものではありません。
warmup_epochs 3.0 0.0～50.0 ウォームアップのエポック数です。モダン構成は小数に対応し、クラシック構成はコサイン方針の場合のみ調整できます。総エポック数未満にしてください。
warmup_momentum 0.8 0.0～1.0 モダンの検出・セグメンテーション・回転検出で使用するウォームアップ時の初期モメンタムです。
warmup_bias_lr 0.1 0.0～1.0 モダンの検出・セグメンテーション・回転検出で、ウォームアップ中のバイアス初期学習率を指定します。auto オプティマイザーは 0 に設定します。
degrees 0.0 0.0～180.0 学習時のランダム回転の最大絶対角度です。0 で無効にします。分類では本ソフトウェアの明示的なランダム回転処理を使用します。
flipud 0.0 0.0～1.0 学習時に上下反転する確率です。
fliplr 0.5 0.0～1.0 学習時に左右反転する確率です。
translate 0.1 0.0～1.0 学習時の平行移動量です。画像サイズに対する比率であり、画素数ではありません。
scale 0.0 0.0～1.0 学習時のランダムスケール変動幅です。入力サイズや推論時の拡大倍率ではありません。
mosaic 0.0 0.0～1.0 学習時の Mosaic 適用確率です。エンジンの終盤無効化規則も適用されます。
box 7.5 0.0～20.0 ボックス位置損失の重みです。検出しきい値ではありません。
cls 0.5 0.0～20.0 物体クラス損失の重みです。クラス数ではありません。
dfl 1.5 0.0～20.0 Distribution Focal Loss（DFL）の重みです。この損失の有無はモデル構造によります。
copy_paste 0.1 0.0～1.0 検出では確率に従って同じ画像の物体を重ならない位置へコピーします。セグメンテーションではネイティブのマスクコピー割合を使用します。安全な配置先がない場合はスキップし、OBB にはこの設定はありません。
erasing 0.4 0.0～1.0 検出とセグメンテーションでは物体ボックス外の背景のみを消去し、物体とアノテーションを保持します。OBB にはこの設定はありません。
model_path "ats-m.pt" 説明を参照（テキスト・選択肢・パス） タスクに対応するプリセット重みを選択します。実際のファイルはソフトウェアの同梱フォルダーから検出します。
dataset_path 未選択 / 設定を継承 説明を参照（テキスト・選択肢・パス） 現在のタスク用のデータセットを選択します。形式と学習・検証の規則は対応する構成の章を参照してください。

モダン画像分類¶

パラメーター 画面の既定値・渡される値 入力可能な数値範囲 実際の意味
imgsz 960 説明を参照（テキスト・選択肢・パス） モダン構成の単一入力サイズです。分類は前処理規則に従ってクロップし、検出・セグメンテーション・回転検出はエンジン規則に従って拡縮・パディングします。任意の高さと幅を直接設定するものではありません。
epochs 500 1～10000 学習の最大エポック数です。モダン構成では早期終了や手動停止によって、それ以前に終了する場合があります。

optimizer "AdamW" 説明を参照（テキスト・選択肢・パス） オプティマイザーを選択します。モダンの auto は手動の初期学習率とモメンタムを上書きし、ウォームアップのバイアス学習率を 0 に設定します。クラシックの config は YAML を使用します。
lr0 0.0005 1e-05～0.1 モダン分類の初期学習率です。optimizer=auto の場合はエンジンが再選択します。検出・セグメンテーション・回転検出のページにはこの入力欄はありません。
lrf 0.01 0.0001～1.0 モダン分類の最終学習率倍率です。初期学習率に対する比率であり、独立した絶対学習率ではありません。
momentum 0.9 0.0～1.0 SGD 系ではモーメンタム、Adam 系では通常 beta1 に対応します。モダンの auto で上書きされる場合があります。
weight_decay 0.05 0.0～0.5 重み減衰係数です。クラシック構成の既定の負値は設定の使用を意味し、負の減衰係数をエンジンに渡すものではありません。
warmup_epochs 5.0 0.0～50.0 ウォームアップのエポック数です。モダン構成は小数に対応し、クラシック構成はコサイン方針の場合のみ調整できます。総エポック数未満にしてください。

flipud 0.5 0.0～1.0 学習時に上下反転する確率です。
fliplr 0.5 0.0～1.0 学習時に左右反転する確率です。
crop_fraction 1.0 0.1～1.0 モダン分類の短辺保持率です。1 未満の場合、短辺を imgsz/比率 まで拡大してから中央クロップします。学習・検証・ソフトウェア推論で同じ中央領域の規則を使い、学習にはさらにランダム拡張を加えます。
model_path "ats-m-cls.pt" 説明を参照（テキスト・選択肢・パス） タスクに対応するプリセット重みを選択します。実際のファイルはソフトウェアの同梱フォルダーから検出します。
