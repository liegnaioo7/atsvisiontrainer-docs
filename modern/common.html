现代架构通用参数与增强¶

四种任务共享基础训练参数，但不是每一项增强都适用于每种任务。页面中实际存在的控件及默认值见全架构参数核对表。

基础参数¶

参数 功能与使用要点
模型权重 选择与任务匹配的预置权重。分类、检测、分割和 OBB 权重不能随意混用。
imgsz 单尺寸输入。检测/分割/OBB 按引擎规则缩放、填充；分类还有自己的短边缩放与裁剪。
epochs 最大轮数，不是保证一定运行到的轮数。
patience 验证指标连续不改善的耐心轮数；0 关闭早停。正常达到 epochs 不算早停。
batch 每批图片数；增大通常增加显存占用，不保证按比例加速。
workers 数据加载进程数，0 在主进程加载。此项不是“训练线程数”或 GPU 数量。
device auto 由引擎选择；gpu 映射第 0 张 GPU；cpu 在 CPU 上训练。
seed 随机种子，用于控制可控随机性。
amp GPU 自动混合精度开关；不表示所有张量强制半精度。

尺寸输入框当前只解析单个数字。输入非纯数字文本时，会回到默认尺寸（检测/分割/OBB 为 640，分类为 960），而不是解析 640×480 或尺寸列表。请核对实际日志，不要用这个输入框设置矩形高宽。

优化器¶

optimizer=auto 会重新选择优化器、初始学习率及动量，并将 warmup_bias_lr 设为 0。希望使用手动学习率或动量时，选择明确的优化器。

现代分类有 lr0、lrf 输入框；检测、分割、OBB 页面没有单独的学习率输入框，不要按照其他软件的教程寻找不存在的控件。分类 lrf 是最终学习率相对初始值的倍率。

SGD 类使用 momentum；Adam 类对应 beta1。weight_decay 为权重衰减。warmup_epochs 为预热轮数，可输入小数；检测、分割和 OBB 还提供预热初始动量及偏置学习率。

位置与几何增强¶

degrees 表示随机旋转的最大绝对角度；flipud、fliplr 为翻转概率；translate 为相对图像尺寸的平移幅度；scale 为随机缩放幅度。它们不是推理后处理参数。

mosaic 为拼图概率，同时遵循引擎自身的末期关闭规则。界面没有独立开放末期关闭轮数，不应把当前概率解释为最后每一轮都一定启用。

软件适配的增强¶

普通检测的 copy_paste 按概率把同一图片中的一个完整目标复制到无重叠位置。目标源区域有重叠，或没有安全目标位置时跳过。多边形实例分割使用原生掩膜复制粘贴比例。

检测和分割的 erasing 仅擦除目标框外的背景，不遮挡目标框内区域，保留已有标注。它不等同于会任意覆盖物体的分类随机擦除。

OBB 页面不提供 copy_paste 和 erasing。分类页面也不提供上述背景增强。

损失权重¶

检测、分割、OBB 的 box、cls、dfl 是损失系数，不是预测置信度或类别数量。OBB 的 angle 是角度损失系数，与旋转增强的 degrees 无关。模型结构未使用的损失项，不会因为界面传递了系数就凭空出现。

输出位置¶

检测、分割、OBB 结果位于数据集目录下的 runs；分类位于数据集同级的“数据集名_runs”。实际实验目录以日志、图表“打开实验目录”及训练历史登记的路径为准。

软件会自动导出 ONNX，simplify=False，不为图简化自动安装 onnxslim。导出失败时查看日志，已有检查点仍可能保留。
