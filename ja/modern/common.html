モダン構成の共通パラメーターとデータ拡張¶

4 タスクは基本設定を共有しますが、すべての拡張がすべてのタスクに適用されるわけではありません。実際の項目と既定値はパラメーター一覧を参照してください。

基本パラメーター¶

パラメーター 機能と使い方
モデルの重み タスクに対応するプリセット重みを選択します。分類・検出・セグメンテーション・OBB の重みは任意に混用できません。
imgsz 入力サイズは単一値です。検出・セグメンテーション・OBB はエンジンの規則で拡大縮小とパディングを行い、分類は固有の短辺リサイズとクロップも使用します。
epochs 最大エポック数であり、必ずその回数まで実行する保証ではありません。
patience 検証指標が連続して改善しない場合の待機エポック数です。0 で早期終了を無効にします。通常どおり epochs に達した終了は早期終了ではありません。
batch バッチあたりの画像数です。増やすと通常 GPU メモリー使用量が増えますが、比例して高速化する保証はありません。
workers データ読み込みプロセス数です。0 はメインプロセスで読み込みます。学習スレッド数や GPU 数ではありません。
device auto はエンジンが選択し、gpu は GPU 0、cpu は CPU で学習します。
seed 制御可能なランダム性を管理する乱数シードです。
amp GPU の自動混合精度です。すべてのテンソルを半精度に固定する機能ではありません。

サイズ欄は単一の数字を解析します。数字以外の文字列は既定値（検出・セグメンテーション・OBB は 640、分類は 960）に戻り、640×480 やリストとしては解釈しません。ログを確認し、矩形サイズの指定には使わないでください。

最適化手法¶

optimizer=auto は最適化手法・初期学習率・モーメンタムを再選択し、warmup_bias_lr を 0 にします。手動の学習率やモーメンタムを使うには最適化手法を明示してください。

モダン分類には lr0 と lrf の入力欄があります。検出・セグメンテーション・OBB には独立した学習率入力欄がありません。他のソフトウェアの手順にある未実装の設定を探さないでください。分類の lrf は初期学習率に対する最終学習率の倍率です。

SGD 系は momentum、Adam 系は beta1 を使用します。weight_decay は重み減衰です。warmup_epochs はウォームアップ期間で、小数も指定できます。物体検出・セグメンテーション・OBB では、ウォームアップ開始時のモーメンタムとバイアス学習率も設定できます。

位置と幾何形状の拡張¶

degrees は回転の最大絶対角度、flipud と fliplr は反転確率、translate は画像サイズに対する移動量、scale はランダムな拡大縮小の幅です。推論の後処理設定ではありません。

mosaic はモザイク合成の確率で、エンジンによる学習終盤の無効化規則にも従います。無効化までのエポック数を別途設定する欄はなく、現在の確率が最後の各エポックでの有効化を保証するわけではありません。

ソフトウェア独自のデータ拡張処理¶

通常の検出の copy_paste は、同じ画像の完全な物体を、確率に従って重なりのない位置へコピーします。コピー元が他の物体と重なる場合や、安全な配置先がない場合はスキップします。ポリゴンのインスタンスセグメンテーションではネイティブのマスクコピー割合を使用します。

検出とセグメンテーションの erasing は物体ボックス外の背景のみを消去し、ボックス内と既存アノテーションを保持します。物体を任意に隠す可能性のある分類のランダム消去とは動作が異なります。

OBB ページには copy_paste と erasing はありません。分類ページにも、これらの背景拡張はありません。

損失の重み¶

検出・セグメンテーション・OBB の box、cls、dfl は損失係数であり、予測信頼度やクラス数ではありません。OBB の angle は角度損失係数であり、回転拡張の degrees とは無関係です。係数を渡しても、モデル構造が使用しない損失項が追加されることはありません。

出力先¶

検出・セグメンテーション・OBB の結果はデータセットフォルダー内の runs に、分類の結果はデータセットと同じ階層の「データセット名_runs」に保存します。実際の実験フォルダーは、ログ、グラフの「実験フォルダーを開く」、学習履歴に登録されたパスで確認してください。

ソフトウェアは simplify=False で ONNX を自動エクスポートし、グラフ簡略化のために onnxslim を自動インストールしません。失敗した場合はログを確認してください。既存チェックポイントは残っている場合があります。
