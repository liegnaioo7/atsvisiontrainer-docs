Riferimento parametri di tutte le architetture¶

I valori predefiniti e gli intervalli seguenti vengono letti dall'interfaccia attuale; le spiegazioni sono state confrontate con gli adattatori del software. Dopo modifiche a preset, dispositivi o YAML avanzati, i valori effettivi dipendono dalla configurazione finale dell'esperimento.

I valori segnaposto Usa configurazione non sono i valori effettivi del motore; un percorso vuoto indica una scelta non ancora effettuata. workers moderno e workers classico su Windows hanno implementazioni diverse.

Rilevamento moderno di oggetti¶

Parametro Valore predefinito / trasmesso dall'interfaccia Intervallo numerico consentito Significato effettivo
imgsz 640 Vedere la descrizione (testo, opzione o percorso) Dimensione singola di input delle architetture moderne. La classificazione ritaglia secondo la propria preelaborazione; rilevamento, segmentazione e rilevamento orientato ridimensionano e aggiungono padding secondo il motore. Non imposta altezza e larghezza arbitrarie.
epochs 1000 1～10000 Numero massimo di epoche; le architetture moderne possono terminare prima per arresto anticipato o interruzione manuale.
patience 100 0～1000 Pazienza dell'arresto anticipato moderno: epoche consecutive senza miglioramento della metrica di validazione. Impostare 0 per disattivarlo.
workers 8 0～64 Le architetture moderne usano processi di caricamento dati; su Windows, quelle classiche usano thread per lettura e preelaborazione parallele con valori maggiori di 0, oppure il caricamento originale con 0.
batch 16 1～512 Immagini elaborate per batch; nel rilevamento anomalie è il batch di estrazione delle caratteristiche. Ridurre il valore se la memoria GPU è insufficiente.
device Non selezionato / usa configurazione Vedere la descrizione (testo, opzione o percorso) Selezionare il dispositivo di calcolo. Il moderno auto lascia decidere al motore; gpu usa il dispositivo 0. Le attività GPU classiche e di anomalie usano la scheda scelta e non passano silenziosamente alla CPU in caso di errore.
seed 42 0～99999 Seme casuale; semi identici non garantiscono risultati identici tra dispositivi o ambienti diversi.
amp true Vedere la descrizione (testo, opzione o percorso) Precisione mista. Interfaccia moderna: True/False. Interfaccia classica: configurazione/disattivata/attivata; l'attivazione esplicita richiede la GPU. AMP classico è disattivato sulla CPU.
optimizer "auto" Vedere la descrizione (testo, opzione o percorso) Selezionare un ottimizzatore. Il moderno auto sovrascrive tasso iniziale e momentum manuali e imposta a 0 il tasso dei bias nel warmup; il classico config usa lo YAML.
momentum 0.937 0.0～1.0 Momento per gli ottimizzatori di tipo SGD; normalmente beta1 per quelli di tipo Adam. La modalità auto moderna può sovrascriverlo.
weight_decay 0.0005 0.0～0.1 Coefficiente di decadimento dei pesi. Nelle architetture classiche, il valore negativo predefinito indica di usare la configurazione; non viene passato al motore un decadimento negativo.
warmup_epochs 3.0 0.0～50.0 Epoche di warmup. Le architetture moderne accettano decimali; quelle classiche consentono la regolazione solo con la strategia coseno e richiedono un valore inferiore alle epoche totali.
warmup_momentum 0.8 0.0～1.0 Momentum iniziale durante il warmup moderno di rilevamento/segmentazione/rilevamento orientato.
warmup_bias_lr 0.1 0.0～1.0 Tasso di apprendimento iniziale dei bias durante il warmup moderno di rilevamento/segmentazione/rilevamento orientato; l'ottimizzatore auto lo imposta a 0.
degrees 0.0 0.0～180.0 Angolo massimo assoluto di rotazione casuale durante l'addestramento; 0 la disattiva. La classificazione usa l'adattatore esplicito di rotazione casuale del software.
flipud 0.0 0.0～1.0 Probabilità di ribaltamento verticale durante l'addestramento.
fliplr 0.5 0.0～1.0 Probabilità di ribaltamento orizzontale durante l'addestramento.
translate 0.1 0.0～1.0 Entità della traslazione in addestramento relativa alla dimensione dell'immagine, non un numero di pixel.
scale 0.0 0.0～1.0 Entità della scala casuale in addestramento, non dimensione di input desiderata né ingrandimento di inferenza.
mosaic 0.0 0.0～1.0 Probabilità di Mosaic durante l'addestramento; restano valide le regole del motore per disattivarlo nella fase finale.
box 7.5 0.0～20.0 Peso della perdita di localizzazione dei riquadri, non una soglia di rilevamento.
cls 0.5 0.0～20.0 Peso della perdita di classificazione degli oggetti, non il numero di classi.
dfl 1.5 0.0～20.0 Peso della Distribution Focal Loss (DFL); la sua presenza dipende dall'architettura del modello.
copy_paste 0.1 0.0～1.0 Il rilevamento copia con una certa probabilità un oggetto della stessa immagine in una posizione senza sovrapposizioni; la segmentazione usa la frazione nativa di copia delle maschere. Si salta l'operazione se manca una posizione sicura; il controllo non è disponibile per OBB.
erasing 0.4 0.0～1.0 Rilevamento e segmentazione cancellano solo lo sfondo esterno ai riquadri, preservando oggetti e annotazioni; OBB non dispone di questo controllo.
model_path "ats-m.pt" Vedere la descrizione (testo, opzione o percorso) Selezionare pesi predefiniti adatti all'attività. Il software individua i file effettivi nelle directory incluse.
dataset_path Non selezionato / usa configurazione Vedere la descrizione (testo, opzione o percorso) Selezionare un dataset per l'attività attuale; vedere il capitolo dell'architettura per formati e regole di addestramento/validazione.

warmup_epochs 5.0 0.0～50.0 Epoche di warmup. Le architetture moderne accettano decimali; quelle classiche consentono la regolazione solo con la strategia coseno e richiedono un valore inferiore alle epoche totali.
degrees 180.0 0.0～180.0 Angolo massimo assoluto di rotazione casuale durante l'addestramento; 0 la disattiva. La classificazione usa l'adattatore esplicito di rotazione casuale del software.
flipud 0.5 0.0～1.0 Probabilità di ribaltamento verticale durante l'addestramento.
fliplr 0.5 0.0～1.0 Probabilità di ribaltamento orizzontale durante l'addestramento.
crop_fraction 1.0 0.1～1.0 Frazione di mantenimento del lato corto per la classificazione moderna. Sotto 1, il lato corto viene prima ingrandito a imgsz/frazione e poi ritagliato al centro. Addestramento, validazione e inferenza del software condividono questa regola della regione centrale; l'addestramento aggiunge comunque aumenti casuali.
model_path "ats-m-cls.pt" Vedere la descrizione (testo, opzione o percorso) Selezionare pesi predefiniti adatti all'attività. Il software individua i file effettivi nelle directory incluse.
dataset_path Non selezionato / usa configurazione Vedere la descrizione (testo, opzione o percorso) Selezionare un dataset per l'attività attuale; vedere il capitolo dell'architettura per formati e regole di addestramento/validazione.

Rilevamento classico di oggetti 2.7.0¶

Parametro Valore predefinito / trasmesso dall'interfaccia Intervallo numerico consentito Significato effettivo
python "<cartella del software>\\Paddle\\runtime-cpu\\python.exe" Vedere la descrizione (testo, opzione o percorso) Interprete dell'ambiente classico indipendente; individuato automaticamente dalla selezione CPU/GPU oppure impostato manualmente su un ambiente compatibile.
config "<cartella del software>\\Paddle\\PaddleDetection-2.7.0\\configs\\ppyoloe\\ppyoloe_plus_crn_s_80e_coco.yml" Vedere la descrizione (testo, opzione o percorso) YAML di riferimento: s/m/l/x/sod sono preset di rilevamento classico; la classificazione usa i nomi reali delle configurazioni.
output "<cartella del software>\\runs\\classic_det" Vedere la descrizione (testo, opzione o percorso) Radice di output dell'addestramento classico; ogni esecuzione crea una sottodirectory di esperimento indipendente con data e ora.
epochs 100 1～100000 Numero massimo di epoche; le architetture moderne possono terminare prima per arresto anticipato o interruzione manuale.
batch 4 1～4096 Immagini elaborate per batch; nel rilevamento anomalie è il batch di estrazione delle caratteristiche. Ridurre il valore se la memoria GPU è insufficiente.
seed 42 0～99999 Seme casuale; semi identici non garantiscono risultati identici tra dispositivi o ambienti diversi.
device "cpu" Vedere la descrizione (testo, opzione o percorso) Selezionare il dispositivo di calcolo. Il moderno auto lascia decidere al motore; gpu usa il dispositivo 0. Le attività GPU classiche e di anomalie usano la scheda scelta e non passano silenziosamente alla CPU in caso di errore.
weight_mode "config" Vedere la descrizione (testo, opzione o percorso) config segue le impostazioni di preaddestramento; local usa un .pdparams locale; random inizializza casualmente. config può scaricare pesi.
weights Non selezionato / usa configurazione Vedere la descrizione (testo, opzione o percorso) File .pdparams locale usato solo selezionando pesi preaddestrati locali.
dataset.mode "coco" Vedere la descrizione (testo, opzione o percorso) Il rilevamento classico usa coco come predefinito, la classificazione usa classification; config mantiene le impostazioni del dataset nello YAML.
dataset.root Non selezionato / usa configurazione Vedere la descrizione (testo, opzione o percorso) Radice del dataset classico. Selezionare una cartella; le regole di riconoscimento sono nel capitolo sui dataset.
dataset.evaluate_on_train false Vedere la descrizione (testo, opzione o percorso) Disabilitato per impostazione predefinita. Se abilitato, tutte le immagini e annotazioni di addestramento sostituiscono il set di validazione separato; le metriche riflettono solo l’adattamento al set di addestramento.
training_options.image_size_mode "config" Vedere la descrizione (testo, opzione o percorso) Rilevamento classico: config mantiene le dimensioni configurate; fixed unifica addestramento/validazione/esportazione; eval modifica solo validazione/test/esportazione.
training_options.image_height 640 96～8192 Altezza personalizzata del rilevamento classico, 96–8192 e multipla di 32; inattiva nella modalità dimensioni config.
training_options.image_width 640 96～8192 Larghezza personalizzata del rilevamento classico, 96–8192 e multipla di 32; inattiva nella modalità dimensioni config.
training_options.workers 0 0～32 Le architetture moderne usano processi di caricamento dati; su Windows, quelle classiche usano thread per lettura e preelaborazione parallele con valori maggiori di 0, oppure il caricamento originale con 0.
training_options.learning_rate Non selezionato / usa configurazione 0.0～100.0 Tasso iniziale classico; 0 nell'interfaccia indica di usare la configurazione. Senza sovrascrittura viene passato un valore vuoto.
