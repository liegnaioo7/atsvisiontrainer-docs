经典架构通用参数与独立环境¶

经典目标检测对应 ATSLegacy 2.7.0，经典分类对应 ATSLegacy 2.5.0。版本标识是架构/配置版本，不是现代架构版本。两个页面共享部分控件，但数据预处理和参数映射分别实现。

参数覆盖优先级¶

先加载所选模型 YAML 及其基础配置，再生成本次实验的独立配置，最后应用界面中明确填写的覆盖项。不会回写内置模型 YAML。选择“沿用配置”的项目保留原配置，不等于使用一个统一的固定默认值。

训练轮数、批次和随机种子直接使用界面值。默认轮数 100、批次 4、种子 42；其他优化项默认沿用配置。每次实验保存 effective_det.yaml 或 effective_clas.yaml，可据此核查真实尺寸、数据路径、类别、学习率和加载器设置。

权重初始化¶

选项 实际行为
使用配置文件中的预训练设置 沿用 YAML；URL 可能下载权重，也可能命中已有缓存。不保证每台客户机都已有缓存。
使用本地预训练权重 指定兼容的 .pdparams，用于本次初始化。不是“断点续训”开关。
随机初始化 不加载配置中的预训练权重，从随机参数开始；仍需要有效模型配置。

离线时选择本地权重或随机初始化。仅凭训练架构文件夹存在，不能认为预训练权重也已随附。

学习率与优化器¶

初始学习率为 0 的界面显示“沿用配置”；它不会向引擎设置一个 0 学习率。权重衰减为界面“沿用配置”占位值时同样不覆盖。

优化器可沿用配置或明确选择 Momentum、SGD、Adam、AdamW。切换时软件会适配其参数结构；AdamW 使用数值衰减，而不是把旧优化器的正则化字典直接传入。

学习率策略 行为
沿用配置 保留原有里程碑、总周期及预热设置。修改总训练轮数不会自动改写这个策略的全部周期。
固定学习率 采用本次配置的初始学习率，不设置界面预热。
余弦退火 按本次总轮数重建周期，可设置整数预热轮数，必须小于总轮数。

训练轮数与策略必须对应

如果参考模型原计划 80 或 96 轮，而本次训练到 300 轮，仍选择“沿用配置”，原学习率计划可能先于训练结束而衰减到底。希望周期匹配本次轮数时，选择界面的余弦策略并核对最终 YAML。

数据增强与 AMP¶

“沿用模型增强策略”保留原有模型增强；“关闭随机增强”使用验证预处理替代随机训练增强。归一化、排列通道及必要尺寸处理仍然存在。

AMP 可沿用配置、关闭或开启。显式开启需要 GPU；CPU 关闭 AMP。“沿用配置”并不保证 GPU 上一定开启，仍由模型配置决定。

Windows workers 与显卡¶

Windows 原生经典环境的原生多进程加载受限。软件在 workers>0 时采用独立进程内部的线程并行读取和预处理，0 使用原有方式。可先尝试 2 或 4，数值更大不保证更快。

每次任务只使用选择的一张 NVIDIA 显卡；机器有多张卡时可任选其一，不支持同一经典模型的原生 Windows 多卡联合训练。独立进程内部通常显示 GPU 0，这是设备可见性映射，不代表忽略了物理卡选择。

输出根目录下每次生成独立的时间戳目录。训练和自动导出使用经典独立环境，不更改现代架构或异常检测环境。完整参数范围见参数核对表。
