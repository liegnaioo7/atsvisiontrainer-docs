ATSAnomaly 异常检测¶

适合仅使用正常 OK 图片建立特征库，再判断新图片是否偏离正常分布的场景。当前实现基于 PatchCore 方法，不按普通分类方式进行多轮梯度训练。

训练与校准数据¶

训练目录只放 OK 图片。独立校准目录也只放 OK 图；留空时按内容去重，固定随机种子 42，留出约 20% 做校准，至少需要 3 张不同图片。校准图不参与特征库构建，训练与独立校准之间内容重复会报错。

仅用 OK 图估计阈值，不能据此声称已测得缺陷召回率、误检率或生产精度；需要独立 OK/NG 测试样本验证业务效果。

构建参数¶

参数 作用
骨干 ResNet18（较快）或 Wide ResNet50-2（高容量），使用随附预训练权重且冻结参数
图像尺寸 默认 256；完整图片、ROI 或每个切片缩放为正方形，可能改变长宽比；64～1024 且为 32 的倍数
提取批大小 默认 2，范围 1～16；决定特征提取批次，显存不足时减小
核心集保留比例 默认 0.01；从候选特征中保留的比例，不是保留训练图片的比例
候选特征上限 默认 50000，超出时有界抽样，限制参与核心集选择的候选数量
核心集特征上限 默认 5000，限制最终记忆库特征数

最终核心集数量为 min(核心集特征上限, max(1, int(候选特征数 × 保留比例)))。特征库和图像尺寸增大通常会增加内存、显存及推理计算量。

此页面没有学习率、优化器、epochs 或早停参数；进度分为正常特征提取、核心集采样和 OK 阈值校准三个阶段。

ROI、切片与校准¶

点击“可视化选择 ROI”，打开与训练数据视角一致的参考图片，在图上拖动绘制矩形，并拖动边角调整大小；百分比数值和图上选区实时同步。暗色区域为检测范围之外。“完整图像”恢复全图选区，“应用 ROI”自动启用 ROI 并写回训练页面，取消保留原设置。参考图片用于定位检测区域，训练图片由训练目录决定。

ROI 默认关闭，启用后按原图宽高百分比设置左、上、右、下边界，分别默认为 0、0、100、100。先裁出 ROI，再在区域内切片；切片默认关闭，启用时默认边长 512 像素、重叠比例 0.25。每块缩放到“图像尺寸”，边缘自动补齐覆盖，区域不足一块时按实际尺寸处理。重叠处取最大异常响应，热力图和掩膜还原到原图坐标；叠加图在 ROI 外保留原图，异常面积比例仅统计 ROI 内像素。

近邻数量默认 9，可设为 1～32，实际取值不超过特征库数量。校准分位数默认 0.99，可设为 0.9～1；安全系数默认 1.05，可设为 1～3。图像阈值和像素阈值分别由 OK 校准图片的图像分数与像素峰值估计，阈值等于指定分位数乘以安全系数。更改这些建模参数后，应重新构建模型并用独立 OK/NG 数据比较漏检和误报。

ROI、切片和近邻数量保存为模型设置，推理与测试评估自动读取。新版保存模型格式 v2，并支持加载原有 v1 模型；原有模型按完整图片处理。切片会增加特征提取和推理耗时，核心集大小仍受候选上限、保留比例和特征上限约束。

阈值与推理¶

在“异常推理验证”中，可从“历史训练模型”选择已有模型，也可浏览本地模型文件。历史列表仅显示模型文件仍存在的异常检测记录；导入旧实验可在“历史训练”页面添加历史目录，再刷新模型列表。推理完成后，“本次推理结果”显示实际保存目录，点击旁边的“打开结果目录”可直接访问；输出位于“结果输出目录”下新建的时间戳子目录。

模型保存为 model.patchcore.pt，推理位于本页面的“异常推理验证”。支持单图或图片文件夹。

异常分数是特征距离，不是概率，不要求落在 0～1。图像判定倍率和像素掩膜倍率分别默认为 1：小于 1 更敏感，大于 1 更宽松。图像分数达到图像阈值判为 NG，像素倍率单独调整掩膜范围；测试评估中选定的倍率只应用到图像判定。

结果包括 OK/NG、异常分数、热力图、叠加图、掩膜、原始分数图及 JSON/CSV。输出目录不得位于输入图片目录中，防止结果再次被当作输入。

当前模型格式不是通用 ONNX、普通分类 PT 或经典推理模型；不要在主“模型推理验证”里选择它。CPU 和单张 NVIDIA GPU 均使用独立异常检测环境。

OK/NG 测试评估¶

打开“OK/NG 测试评估”，选择历史模型或本地模型，分别指定独立的 OK、NG 测试图片目录。两个目录都必须有图片，且不能相互包含；支持递归读取子目录。测试图不得参与模型构建或阈值校准，同一图片内容不能同时标为 OK 和 NG。

倍率默认从 0.5 到 1.5，步长 0.1；按起点加步长取值，不强制追加终点，单次最多比较 201 个倍率。每张图只评分一次，每个倍率的实际阈值等于模型原始图像阈值乘以倍率，分数大于等于阈值判为 NG。评估结果用于选择后续推理倍率，模型文件不因评估而改写。

NG 为正类。漏检是 NG 判为 OK，误报是 OK 判为 NG；NG 召回率为 TP / (TP + FN)，OK 误报率为 FP / (FP + TN)，NG 精确率为 TP / (TP + FP)。没有预测 NG 时精确率显示为“—”。F1 为精确率与召回率的调和平均。这里评估整张图片，不计算像素级分割精度。

结果目录保存 evaluation.json、倍率对比表 threshold_comparison.csv 和逐图分数 evaluation_scores.csv。逐图表包含真实 OK/NG 标签、异常分数和原始倍率 1 的判定。选中对比表的一行，点击“将所选倍率用于推理”即可应用到同一模型；更换模型后须重新评估。阈值调整完成后，应再用另一份独立验收数据确认漏检与误报表现。

完整范围见异常检测参数表。
