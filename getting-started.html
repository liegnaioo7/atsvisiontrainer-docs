快速开始¶

  1. 根据任务选择现代架构、经典架构或异常检测。类别判断用分类，普通框用目标检测，掩膜用实例分割，带方向的框用旋转框检测。
  2. 准备对应格式的数据集。经典检测和分类只需选择一个数据集文件夹；现代架构使用各自的标签格式。
  3. 选择模型、设备和输出相关选项。经典及异常检测使用各自独立环境；可以从多张 NVIDIA 显卡中选择一张，当前 Windows 方案不支持同一经典模型联合多卡训练。
  4. 先用较小批次和少量轮数检查路径、标注、显存及输出，再开展正式训练。这里的流程检查不用于判断最终精度。
  5. 启动后到“控制台日志”查看训练图表和原始日志。图表用于看趋势，原始日志用于查看初始化、验证、导出和错误详情。
  6. 训练成功后查看自动导出的模型。经典训练完成与导出完成是两个阶段；导出失败会保留已保存的训练权重。
  7. 到“训练历史”打开实验文件夹，或选择模型进入推理验证。异常检测的推理位于异常检测自己的页面。

启动任务时会读取一份参数。随后修改界面控件不会改变已经启动的任务；修改应在下一次任务启动前完成。

关闭软件会弹出确认，默认选择取消。任务运行期间确认退出会终止任务。软件正在删除训练文件时，需要等待清理完成后再退出。

三类运行环境¶

架构 训练方式 设备选择
四种现代架构 现代训练引擎 auto / gpu / cpu；gpu 为第 0 张
两种经典架构 独立经典环境 CPU 或任意选择的一张 NVIDIA GPU
异常检测 独立异常检测环境 CPU 或任意选择的一张 NVIDIA GPU

手动选择 GPU 后，不应把失败理解为“软件已经自动改用 CPU”。经典及异常检测 GPU 不可用时会报错，需查看日志并检查环境。
