經典架構通用參數與獨立環境¶

經典目標偵測對應 ATSLegacy 2.7.0，經典分類對應 ATSLegacy 2.5.0。版本標識是架構/配置版本，不是現代架構版本。兩個頁面共享部分控制項，但資料前處理和參數對映分別實現。

參數覆蓋優先順序¶

先載入所選模型 YAML 及其基礎配置，再生成本次實驗的獨立配置，最後應用介面中明確填寫的覆蓋項。不會回寫內建模型 YAML。選擇“沿用配置”的專案保留原配置，不等於使用一個統一的固定預設值。

訓練輪數、批次和隨機種子直接使用介面值。預設輪數 100、批次 4、種子 42；其他最佳化項預設沿用配置。每次實驗儲存 effective_det.yaml 或 effective_clas.yaml，可據此核查真實尺寸、資料路徑、類別、學習率和載入器設定。

權重初始化¶

選項 實際行為
使用配置檔案中的預訓練設定 沿用 YAML；URL 可能下載權重，也可能命中已有快取。不保證每臺客戶機都已有快取。
使用本地預訓練權重 指定相容的 .pdparams，用於本次初始化。不是“斷點續訓”開關。
隨機初始化 不載入配置中的預訓練權重，從隨機參數開始；仍需要有效模型配置。

離線時選擇本地權重或隨機初始化。僅憑訓練架構資料夾存在，不能認為預訓練權重也已隨附。

學習率與最佳化器¶

初始學習率為 0 的介面顯示“沿用配置”；它不會向引擎設定一個 0 學習率。權重衰減為介面“沿用配置”佔位值時同樣不覆蓋。

最佳化器可沿用配置或明確選擇 Momentum、SGD、Adam、AdamW。切換時軟體會適配其參數結構；AdamW 使用數值衰減，而不是把舊最佳化器的正則化字典直接傳入。

學習率策略 行為
沿用配置 保留原有里程碑、總週期及預熱設定。修改總訓練輪數不會自動改寫這個策略的全部週期。
固定學習率 採用本次配置的初始學習率，不設定介面預熱。
餘弦退火 按本次總輪數重建週期，可設定整數預熱輪數，必須小於總輪數。

訓練輪數與策略必須對應

如果參考模型原計劃 80 或 96 輪，而本次訓練到 300 輪，仍選擇“沿用配置”，原學習率計劃可能先於訓練結束而衰減到底。希望週期匹配本次輪數時，選擇介面的餘弦策略並核對最終 YAML。

資料增強與 AMP¶

“沿用模型增強策略”保留原有模型增強；“關閉隨機增強”使用驗證前處理替代隨機訓練增強。歸一化、排列通道及必要尺寸處理仍然存在。

AMP 可沿用配置、關閉或開啟。顯式開啟需要 GPU；CPU 關閉 AMP。“沿用配置”並不保證 GPU 上一定開啟，仍由模型配置決定。

Windows workers 與顯示卡¶

Windows 原生經典環境的原生多程序載入受限。軟體在 workers>0 時採用獨立程序內部的執行緒並行讀取和前處理，0 使用原有方式。可先嚐試 2 或 4，數值更大不保證更快。

每次任務只使用選擇的一張 NVIDIA 顯示卡；機器有多張卡時可任選其一，不支援同一經典模型的原生 Windows 多卡聯合訓練。獨立程序內部通常顯示 GPU 0，這是裝置可見性對映，不代表忽略了物理卡選擇。

輸出根目錄下每次生成獨立的時間戳目錄。訓練和自動匯出使用經典獨立環境，不更改現代架構或異常偵測環境。完整參數範圍見參數核對表。
