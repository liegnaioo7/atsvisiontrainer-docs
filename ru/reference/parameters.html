Справочник параметров всех архитектур¶

Дефолты и числовые диапазоны ниже считываются из текущего пользовательского интерфейса; объяснения проверялись на адаптеры приложения.После изменения предустановок, устройств или продвинутого YAML эффективная конфигурация эксперимента определяет фактические значения обучения.

Использование заполнителей конфигурации не является учебными значениями двигателя; пустой путь означает отсутствие выбора. Современные workers и классические работники Windows используют разные реализации.

Современное обнаружение объектов¶

Параметр Дефолт интерфейса / переданное значение Численный диапазон входных данных Фактический смысл
imgsz 640 См. описание (текст, опция или путь) Единый входной размер для современных моделей. Классификация использует собственную обрезку, а обнаружение, сегментация и OBB масштабируют и дополняют изображение по правилам движка. Произвольная высота и ширина здесь отдельно не задаются.
epochs 1000 1～10000 Максимум эпох обучения. Современное обучение может завершиться раньше из-за ранней остановки или остановки пользователем.
patience 100 0～1000 Число эпох подряд без улучшения метрики валидации до ранней остановки. Значение 0 отключает раннюю остановку.
workers 8 0～64 В современных архитектурах задаёт число процессов загрузки данных. В классической среде Windows значение выше 0 включает параллельное чтение и предобработку в потоках. Значение 0 сохраняет исходный загрузчик.
batch 16 1～512 Число изображений в пакете. Для обнаружения аномалий это размер пакета извлечения признаков. Уменьшите его при нехватке видеопамяти.
val_batch 0 0～512 Размер пакета валидации современных моделей. Значение 0 следует фактическому пакету обучения, 1～512 задаёт отдельный размер. Число загрузчиков следует настройке обучения с учётом ограничений движка и системы и не удваивается автоматически. Те же параметры применяются при итоговой повторной проверке лучшей модели.
device Не выбрано / по конфигурации См. описание (текст, опция или путь) Устройство вычислений. В современном режиме auto выбирает устройство автоматически, а gpu использует одну карту из списка. Классические задачи и обнаружение аномалий также используют указанную карту. Если явно выбранный GPU недоступен, задача завершится с ошибкой без автоматического перехода на CPU.
seed 42 0～99999 Начальное значение генератора случайных чисел. Одинаковое значение не гарантирует одинаковые результаты на разных устройствах или в разных средах.
amp true См. описание (текст, опция или путь) Смешанная точность. В современных задачах используются True и False. В классических доступны настройки модели, выключение и включение. Явное включение требует GPU. Классический AMP отключён при обучении на CPU.
optimizer "auto" См. описание (текст, опция или путь) Выбор оптимизатора. В современном режиме auto переопределяет ручные настройки начальной скорости обучения и импульса и устанавливает начальную скорость разогрева для смещений в 0. Классический режим config использует значения YAML.
momentum 0.937 0.0～1.0 Импульс для оптимизаторов семейства SGD. Для семейства Adam обычно соответствует beta1. В современных задачах режим auto может переопределить значение.
weight_decay 0.0005 0.0～0.1 Коэффициент затухания весов. Отрицательное значение по умолчанию в классических задачах означает использование конфигурации. Отрицательный коэффициент не передаётся движку.
warmup_epochs 3.0 0.0～50.0 Число эпох разогрева. Современные задачи допускают дробное значение. Для классических задач параметр доступен при косинусном расписании и должен быть меньше общего числа эпох.
warmup_momentum 0.8 0.0～1.0 Начальный импульс на этапе разогрева для современных задач обнаружения, сегментации и OBB.
warmup_bias_lr 0.1 0.0～1.0 Начальная скорость обучения смещений на этапе разогрева для современных задач обнаружения, сегментации и OBB. Режим auto устанавливает 0.
degrees 0.0 0.0～180.0 Максимальный абсолютный угол случайного поворота при обучении. Значение 0 отключает поворот. Классификация использует отдельное преобразование случайного поворота приложения.
flipud 0.0 0.0～1.0 Вероятность вертикального отражения при обучении.
fliplr 0.5 0.0～1.0 Вероятность горизонтального отражения при обучении.
translate 0.1 0.0～1.0 Величина сдвига при обучении в долях размера изображения, а не в пикселях.
scale 0.0 0.0～1.0 Диапазон случайного масштабирования при обучении. Не задаёт входной размер или коэффициент увеличения при инференсе.
mosaic 0.0 0.0～1.0 Вероятность аугментации Mosaic при обучении. Движок может отключить её на завершающем этапе.
box 7.5 0.0～20.0 Вес потерь локализации рамки. Не задаёт порог обнаружения.
cls 0.5 0.0～20.0 Вес потерь классификации объектов. Не задаёт число классов.
dfl 1.5 0.0～20.0 Вес Distribution Focal Loss (DFL). Наличие этой функции потерь зависит от архитектуры модели.
detection_head "standard" См. описание (текст, опция или путь) По умолчанию используется стандартная детекция. P2 добавляет масштаб высокого разрешения для мелких объектов.
copy_paste 0.1 0.0～1.0 При обнаружении объект с заданной вероятностью копируется в непересекающееся место того же изображения. При сегментации значение задаёт долю нативного копирования масок. Без подходящего места операция пропускается. В OBB параметр отсутствует.
erasing 0.4 0.0～1.0 При обнаружении и сегментации стирается только фон за пределами рамок. Объекты и разметка сохраняются. В OBB параметр отсутствует.
model_path "ats-m.pt" См. описание (текст, опция или путь) Выберите предустановленные веса для нужной задачи. Приложение ищет файл в поставляемом каталоге.
dataset_path Не выбрано / по конфигурации См. описание (текст, опция или путь) Выберите набор данных текущей задачи. Формат и правила обучения и валидации описаны в разделе соответствующей архитектуры.

lr0 0.0005 1e-05～0.1 Начальная скорость обучения для современной классификации. В режиме optimizer=auto её выбирает движок. На страницах обнаружения, сегментации и OBB отдельного поля нет.
lrf 0.01 0.0001～1.0 Конечная скорость обучения современной классификации, выраженная множителем относительно начальной скорости.

degrees 180.0 0.0～180.0 Максимальный абсолютный угол случайного поворота при обучении. Значение 0 отключает поворот. Классификация использует отдельное преобразование случайного поворота приложения.
flipud 0.5 0.0～1.0 Вероятность вертикального отражения при обучении.
fliplr 0.5 0.0～1.0 Вероятность горизонтального отражения при обучении.
crop_fraction 1.0 0.1～1.0 Доля короткой стороны для современной классификации. Если она меньше 1, короткая сторона сначала масштабируется до imgsz/доля, затем выполняется обрезка по центру. Это правило применяется при обучении, валидации и инференсе. Случайные аугментации при обучении выполняются дополнительно.
model_path "ats-m-cls.pt" См. описание (текст, опция или путь) Выберите предустановленные веса для нужной задачи. Приложение ищет файл в поставляемом каталоге.
dataset_path Не выбрано / по конфигурации См. описание (текст, опция или путь) Выберите набор данных текущей задачи. Формат и правила обучения и валидации описаны в разделе соответствующей архитектуры.

coreset_ratio 0.01 0.001～1.0 Доля признаков-кандидатов, сохраняемая в репрезентативном подмножестве. Также действует предел размера подмножества.
max_patches 50000 100～250000 Максимум признаков-кандидатов. При превышении проводится выборка. Параметр не задаёт число обучающих изображений.
max_bank 5000 1～10000 Максимум признаков в итоговом репрезентативном подмножестве. Не задаёт число изображений или классов.
roi_enabled false См. описание (текст, опция или путь) Включение области контроля. По умолчанию она отключена. Поддерживаются прямоугольная и кольцевая формы. Настройка сохраняется в модели.
roi_left 0.0 0.0～100.0 Левая граница ROI в процентах ширины исходного изображения, по умолчанию 0; при включённой ROI должна быть меньше правой.
roi_top 0.0 0.0～100.0 Верхняя граница ROI в процентах высоты исходного изображения, по умолчанию 0; при включённой ROI должна быть меньше нижней.
roi_right 100.0 0.0～100.0 Правая граница ROI в процентах ширины исходного изображения, по умолчанию 100.
roi_bottom 100.0 0.0～100.0 Нижняя граница ROI в процентах высоты исходного изображения, по умолчанию 100.
roi_inner_ratio Не выбрано / по конфигурации См. описание (текст, опция или путь) Отношение внутреннего диаметра кольцевой ROI к внешнему. Для прямоугольника поле пустое. В интерфейсе указывается процент, по умолчанию 70%, диапазон от 5% до 98%.
tiling_enabled false См. описание (текст, опция или путь) Тайлинг при построении модели аномалий, по умолчанию отключён. Построение, калибровка, оценка и инференс используют одинаковые настройки из модели.
tile_size 512 64～4096 Размер тайла в исходных пикселях, по умолчанию 512, диапазон 64–4096. Области меньше тайла обрабатываются в фактическом размере.
tile_overlap 0.25 0.0～0.75 Доля перекрытия соседних тайлов, по умолчанию 0.25, диапазон 0–0.75. Крайние тайлы обеспечивают покрытие; в перекрытиях выбирается максимальный отклик.
neighbors 9 1～32 Число ближайших соседей для сопоставления признаков, по умолчанию 9, диапазон 1–32. Фактическое число не превышает размер банка; сохраняется в модели.
calibration_quantile 0.99 0.9～1.0 Квантиль оценок OK, по умолчанию 0.99, диапазон 0.9–1; отдельно для оценок изображений и пиков пикселей.
calibration_margin 1.05 1.0～3.0 Коэффициент запаса калибровки, по умолчанию 1.05, диапазон 1–3; итоговый порог равен выбранному квантилю, умноженному на коэффициент.
model Не выбрано / по конфигурации См. описание (текст, опция или путь) Для инференса аномалий используется файл model.patchcore.pt, созданный при обучении.
source Не выбрано / по конфигурации См. описание (текст, опция или путь) Изображение или папка изображений для инференса аномалий. Папка результатов должна находиться вне входной папки.
test_ok_dir Не выбрано / по конфигурации См. описание (текст, опция или путь) Независимый каталог изображений OK для оценки аномалий. Он не должен содержать каталог NG или находиться внутри него.
test_ng_dir Не выбрано / по конфигурации См. описание (текст, опция или путь) Независимый каталог изображений NG для оценки аномалий. NG — положительный класс; тестовые изображения не должны участвовать в построении модели или калибровке.
threshold_start 0.5 0.1～10.0 Начальный множитель порога при оценке аномалий, по умолчанию 0.5.
threshold_stop 1.5 0.1～10.0 Верхняя граница множителя при оценке аномалий, по умолчанию 1.5. Значения задаются шагом; конечное значение автоматически не добавляется.
threshold_step 0.1 0.01～10.0 Шаг множителя при оценке аномалий, по умолчанию 0.1; до 201 множителя за запуск.
threshold_multiplier 1.0 0.1～10.0 Множитель порога изображения; меняет только порог OK/NG для изображения. Меньше 1 повышает чувствительность, больше 1 смягчает порог.
output_dir "<software directory>\\runs\\patchcore" См. описание (текст, опция или путь) Корневая папка результатов обнаружения аномалий. Обучение и инференс создают отдельные подпапки экспериментов.
pixel_threshold_multiplier 1.0 0.1～10.0 Множитель порога маски, по умолчанию 1; регулирует только маску. Площадь аномалии считается внутри ROI.
device "cpu" См. описание (текст, опция или путь) Устройство вычислений. В современном режиме auto выбирает устройство автоматически, а gpu использует одну карту из списка. Классические задачи и обнаружение аномалий также используют указанную карту. Если явно выбранный GPU недоступен, задача завершится с ошибкой без автоматического перехода на CPU.
gpu_id 0 См. описание (текст, опция или путь) Физический номер GPU для классических задач и обнаружения аномалий. В отдельном процессе карта отображается как GPU 0. Каждый запуск использует одну карту.
