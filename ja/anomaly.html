ATSAnomaly 異常検出¶

正常な OK 画像のみから特徴量バンクを構築し、新しい画像が正常分布から外れているかを判定する用途に適します。現在の実装は PatchCore 手法に基づき、通常の分類のような複数エポックの勾配学習は行いません。

学習データと校正データ¶

学習フォルダーと独立した校正フォルダーには OK 画像のみを入れます。校正先が空欄の場合、内容による重複除去後、固定乱数シード 42 で約 20% を校正に確保します。少なくとも異なる画像が 3 枚必要です。校正画像は特徴量バンクの構築に使わず、学習と独立校正で内容が重複するとエラーにします。

OK 画像だけで推定したしきい値から、欠陥再現率、誤検出率、本番精度を測定済みとは言えません。独立した OK/NG サンプルで業務上の性能を確認してください。

構築パラメーター¶

パラメーター 作用
バックボーン ResNet18（高速）または Wide ResNet50-2（高容量）。同梱の事前学習済み重みを使用し、パラメーターは固定します。
画像サイズ 既定値 256。画像全体・ROI・各タイルを正方形に変換するため縦横比が変わる場合があります。64～1024、32 の倍数です。
抽出バッチサイズ 既定値 2、範囲 1～16。特徴量抽出のバッチサイズを決めます。GPU メモリーが不足する場合は小さくしてください。
コアセット保持率 既定値 0.01。候補特徴量の保持率であり、学習画像の保持率ではありません。
候補特徴数の上限 既定値 50000。超過時は上限付きサンプリングを行い、コアセット選択に使う候補数を制限します。
コアセット特徴量数上限 既定値 5000。最終特徴量バンクの特徴量数を制限します。

最終コアセット数は min(コアセット特徴量数上限, max(1, int(候補特徴量数 × 保持率))) です。特徴量バンクや画像サイズを大きくすると、通常はメモリー、GPU メモリー、推論計算量が増えます。

このページには学習率、オプティマイザー、epochs、早期終了の設定はありません。進捗は正常特徴量の抽出、コアセットのサンプリング、OK しきい値の校正で構成されます。

ROI・タイル分割・校正¶

「ROI を画像上で選択」をクリックし、学習データと同じ視点の参照画像を開きます。ドラッグして矩形を描き、辺や角をドラッグしてサイズを調整します。割合の数値と画像上の選択領域は連動します。暗い部分は検査対象外です。「画像全体」で全体を選択し直せます。「ROI を適用」で ROI を有効にして学習ページへ反映し、キャンセルでは元の設定を保持します。参照画像は領域を指定するために使用し、学習画像は学習フォルダーから読み取ります。

ROI は既定で無効です。左・上・右・下の境界を元画像の幅・高さに対する割合で指定し、既定値は 0、0、100、100 です。ROI を切り出してからタイル分割します。タイル分割も既定で無効で、有効時の既定値は辺長 512 ピクセル、重複率 0.25 です。各タイルをモデル入力サイズに変換し、端にもタイルを追加して全域を覆います。領域がタイルより小さい場合は実寸を使用します。重複部分は最大応答を採用します。ヒートマップとマスクは元画像座標に戻し、ROI 外の重ね合わせは原画像を保持します。異常面積率は ROI 内のピクセルのみで計算します。

近傍数の既定値は 9、範囲は 1～32 で、特徴メモリ数を超えません。校正分位数の既定値は 0.99、範囲は 0.9～1、安全係数の既定値は 1.05、範囲は 1～3 です。OK 校正画像の画像スコアとピクセル最大値から、それぞれ指定分位数と安全係数の積をしきい値として推定します。これらの構築パラメーターを変更したら、モデルを再構築し、独立した OK/NG データで見逃しと誤検出を比較してください。

「リング形 ROI」を選択し、外側の枠を製品の外縁に合わせてから内径の割合を設定します。内外の輪郭は中心を共有します。特徴バンクの作成、校正、スコア計算には輪郭間の領域を使い、中央の穴と外側の背景はマスクから除外します。リング形 ROI を使うにはモデルを学習し直します。

ROI、タイル設定、近傍数はモデルに保存され、推論と評価で自動適用されます。リング形 ROI のモデルは v3 を使用します。v2 と v1 も読み込めます。v1 は画像全体を処理します。タイル分割により特徴抽出と推論の時間は増えます。コアセットの大きさは候補上限、保持率、特徴上限で制限されます。

しきい値と推論¶

「異常推論検証」では、学習履歴から既存のモデルを選択するか、ローカルのモデルファイルを参照できます。モデルファイルが存在する異常検知の履歴のみが表示されます。過去の実験を取り込むには、学習履歴ページで履歴フォルダーを追加してからモデル一覧を更新してください。推論完了後、「今回の推論結果」に実際の保存先が表示され、隣のボタンで結果フォルダーを開けます。各実行結果は、出力先の下に作成されるタイムスタンプ付きのサブフォルダーに保存されます。

モデルは model.patchcore.pt として保存します。推論はこのページの「異常推論検証」で行い、単一画像または画像フォルダーに対応します。

異常スコアは特徴距離であり、確率ではないため 0～1 に収まる必要はありません。画像判定倍率とピクセルマスク倍率の既定値はそれぞれ 1 で、1 未満は敏感、1 超は緩い判定になります。画像スコアが画像しきい値以上なら NG です。ピクセル倍率はマスク範囲を独立して調整し、テスト評価で選んだ倍率は画像判定にのみ適用します。

結果には OK/NG、異常スコア、ヒートマップ、重ね合わせ画像、マスク、生スコアマップ、JSON/CSV が含まれます。生成結果を再び入力として読み込まないよう、出力先を入力画像フォルダー内に指定することはできません。

このモデル形式は汎用 ONNX、通常の分類 PT、クラシック推論モデルとは異なります。メインの「モデル推論検証」では選択しないでください。CPU と単一の NVIDIA GPU のどちらも、独立した異常検出環境を使用します。

推論後に「推論結果を比較」を開くと、元画像、ヒートマップ、重ね合わせ、マスクを並べて確認できます。拡大比較では ← / → または「前の画像」「次の画像」で、ギャラリーのフィルターと並び順に沿って切り替えられます。

OK/NG テスト評価¶

「OK/NG テスト評価」を開き、履歴またはローカルのモデルを選択し、独立した OK・NG テスト画像フォルダーを指定します。両方に画像が必要で、親子関係にしてはいけません。サブフォルダーも再帰的に読み取ります。テスト画像はモデル構築やしきい値校正に使用していないものにしてください。同じ内容の画像を OK と NG の両方に分類することはできません。

倍率の既定値は開始 0.5、終了 1.5、刻み幅 0.1 です。開始値に刻み幅を加えて値を生成し、終了値は自動追加しません。最大 201 個の倍率を比較できます。各画像のスコアは一度だけ計算します。実際のしきい値はモデルの元の画像しきい値と倍率の積で、スコアがしきい値以上なら NG と判定します。評価でモデルファイルを書き換えることなく、推論倍率を選択できます。

NG を陽性とします。見逃しは NG を OK と判定したもの、誤検出は OK を NG と判定したものです。NG 再現率は TP / (TP + FN)、OK 誤検出率は FP / (FP + TN)、NG 適合率は TP / (TP + FP) です。NG と予測した画像がない場合、適合率は「—」と表示されます。F1 は適合率と再現率の調和平均です。画像単位の評価であり、ピクセル単位のセグメンテーション精度は計算しません。

結果フォルダーには evaluation.json、倍率比較表 threshold_comparison.csv、画像ごとのスコア evaluation_scores.csv が保存されます。画像別の表には正解の OK/NG、異常スコア、元の倍率 1 での判定が含まれます。比較表の行を選び「選択した倍率を推論に適用」を押すと、同じモデルの推論に適用できます。モデルを変更したら再評価してください。しきい値決定後は、別の独立した受け入れ検証データで見逃しと誤検出を確認してください。

全範囲は異常検出パラメーター表を参照してください。
