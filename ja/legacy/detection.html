クラシック物体検出 2.7.0¶

通常の物体検出に使用します。モデル一覧は s / m / l / x / sod と表示します。SOD は実際の小物体モデル設定を使用し、通常モデルのサイズを単に小さくするものではありません。

1 つの COCO フォルダーで学習¶

COCO フォルダーを選び、「データセットを確認」でクラス、学習画像数、検証画像数を確認します。ソフトウェアが実験内のデータ設定を自動生成するため、内蔵の coco_detection を手動編集する必要はありません。

枠のない OK 画像は背景の負例として学習に使用します。独立した検証セットがなければ全学習サンプルを保持し、自動分割・検証・mAP 計算は行いません。損失と学習率は表示されます。学習失敗ではありません。

詳細設定の「YAML のデータ設定を使用」はモデルファイルのデータ設定を保持するため、パスとクラスの正しさは使用者が確認してください。相対パスはクラシック検出の作業ディレクトリを基準に解釈し、任意の外部 YAML の配置先を自動的に基準とするものではありません。

高さと幅の三つのモード¶

サイズモード 学習 検証・テスト・エクスポート
モデルのサイズ設定を使用 マルチスケール学習を含む参照設定を保持 参照設定を保持
固定サイズ 指定した高さ × 幅を使用し、ランダムなサイズ選択を無効化 同じ高さ × 幅を使用
検証・エクスポートのサイズのみ指定 元の学習サイズ方針を保持 指定した高さ × 幅を使用

高さと幅を個別に入力します。両方とも 96～8192 かつ 32 の倍数が必要です。カスタムサイズは元の縦横比を維持せず、画像を直接リサイズします。

高さ 320、幅 640 で、以前の eval_height=320、eval_width=640 のみの変更を再現するには第 3 モードを選びます。学習は元設定の複数の正方形サイズからランダム選択する場合があり、320×640 になるわけではありません。学習もこの矩形に固定するには第 2 モードを選びます。

同時に「ランダム拡張を無効」にした場合、学習前処理もその設定に従って変わります。サイズモードが無効化した拡張を再有効化することはありません。

検証指標¶

独立した検証セットがある場合、モデル設定の検証間隔に従って評価します。毎エポックの指標出力を保証するものではありません。グラフには実際に得られた mAP50-95、mAP50、mAP75 などの検出評価を表示します。分類正解率は、このページの汎用的な検出指標ではありません。

検証セットなし、検証時期に未到達、検証で有効な結果なしは異なる状態であり、グラフでそれぞれ案内します。欠損値を 0 で埋めることはありません。実際に計算された 0 はそのまま保持します。

自動エクスポート¶

学習終了後、保存済みチェックポイントを自動選択し、公式の推論エクスポートを実行します。成功すると、実験内の export/export_det には通常次のファイルが生成されます。

model.pdmodel
model.pdiparams
model.pdiparams.info
infer_cfg.yml

実際のパスはエクスポート完了ログを確認してください。infer_cfg.yml は実際の前処理とクラスを記録し、指定した高幅は入力と前処理へ反映されます。エクスポートは CPU で行い、学習が GPU でなかったという意味ではありません。

その他の最適化手法、読み込み、初期化はクラシック共通パラメーター、全項目は検出パラメーター表を参照してください。

学習データによる検証¶

既定ではオフです。COCO モードでオンにすると、独立した検証セットの代わりにすべての学習画像とアノテーションで評価します。自動分割や元データの変更は行いません。独立した検証セットがあっても、学習データを使って検証します。YAML のデータ設定を使用する場合、このオプションは無効です。

学習データでの AP/mAP は、そのデータへの適合度のみを示し、未知の画像への汎化性能を示すものではありません。検証はモデル設定の間隔で実行されます。元のログには最高 AP の情報が残り、グラフと過去の指標には検証データの出所が表示されます。
