快速開始¶

  1. 根據任務選擇現代架構、經典架構或異常偵測。類別判斷用分類，普通框用目標偵測，遮罩用實例分割，帶方向的框用旋轉框偵測。
  2. 準備對應格式的資料集。經典偵測和分類只需選擇一個資料集資料夾；現代架構使用各自的標籤格式。
  3. 選擇模型、裝置和輸出相關選項。經典及異常偵測使用各自獨立環境；可以從多張 NVIDIA 顯示卡中選擇一張，當前 Windows 方案不支援同一經典模型聯合多卡訓練。
  4. 先用較小批次和少量輪數檢查路徑、標註、顯示記憶體及輸出，再開展正式訓練。這裡的流程檢查不用於判斷最終精度。
  5. 啟動後到“控制檯日誌”檢視訓練圖表和原始日誌。圖表用於看趨勢，原始日誌用於檢視初始化、驗證、匯出和錯誤詳情。
  6. 訓練成功後檢視自動匯出的模型。經典訓練完成與匯出完成是兩個階段；匯出失敗會保留已儲存的訓練權重。
  7. 到“訓練歷史”開啟實驗資料夾，或選擇模型進入推論驗證。異常偵測的推論位於異常偵測自己的頁面。

啟動任務時會讀取一份參數。隨後修改介面控制項不會改變已經啟動的任務；修改應在下一次任務啟動前完成。

關閉軟體會彈出確認，預設選擇取消。任務執行期間確認退出會終止任務。軟體正在刪除訓練檔案時，需要等待清理完成後再退出。

三類執行環境¶

架構 訓練方式 裝置選擇
四種現代架構 現代訓練引擎 auto / gpu / cpu；gpu 為第 0 張
兩種經典架構 獨立經典環境 CPU 或任意選擇的一張 NVIDIA GPU
異常偵測 獨立異常偵測環境 CPU 或任意選擇的一張 NVIDIA GPU

手動選擇 GPU 後，不應把失敗理解為“軟體已經自動改用 CPU”。經典及異常偵測 GPU 不可用時會報錯，需檢視日誌並檢查環境。
