Справка ATSVisionTrainer¶

Руководство описывает интерфейс и параметры приложения для четырёх современных архитектур, двух классических архитектур и обнаружения аномалий. Выберите задачу и подготовьте соответствующий набор данных. У каждой архитектуры своя конфигурация.

Задача Раздел руководства
Первое обучение Быстрый старт
Подготовить обнаружение, классификацию или данные с ориентированной коробкой Подготовка наборов данных
Найти объекты с коробками Современное обнаружение, классическое обнаружение 2.7.0
Классифицировать целое изображение Современная классификация, классическая классификация 2.5.0
Выведите пиксельную область каждого объекта Сегментация экземпляров
Ориентированные на выход ящики объектов Обнаружение объектов с повёрнутыми рамками
Обнаружение аномалий с использованием только ОК изображений Обнаружение аномалий
Обзор результатов обучения или свободного дискового пространства История обучения
Проверьте по умолчанию, диапазон и значение каждого параметра Справочник параметров

Онлайн-руководство можно читать прямо в браузере. Автономная справка входит в комплект приложения и открывается из меню «Справка».

Язык документации можно изменить на панели вверху страницы.

О значениях по умолчанию

Дефолтами в этом руководстве являются текущие начальные значения пользовательского интерфейса, а не предполагаемые значения для каждой модели YAML. Когда классическая архитектура использует свою конфигурацию, конечные значения обучения исходят из выбранной конфигурации модели. Используйте эффективную конфигурацию каждого эксперимента и необработанный журнал для проверки фактического поведения.

В переводе могут быть неточности. Сообщите о них через раздел Обратная связь в приложении. Укажите язык документации и заголовок страницы, а также процитируйте нужный фрагмент. Спасибо за понимание и замечания.
