Training charts and raw logs¶

The console retains Training charts and Raw logs as separate views. Charts do not replace logs and never invent metrics that were not produced.

Metrics by architecture¶

Task Chart meaning
Modern detection/segmentation/OBB Training and validation loss, actual detection evaluation metrics, learning rate
Modern classification Classification loss, actual classification accuracy and learning rate
Classic detection Training loss, actual validation results such as mAP, learning rate
Classic classification Training/validation loss, actual accuracy and other metrics, learning rate
Anomaly detection Feature and coreset sizes, calibration thresholds and time per construction stage; not gradient loss curves

Without an independent validation set for classic COCO, the score panel states training only, no mAP calculation. With validation data, evaluation still follows the model configuration's interval, so values are not guaranteed every epoch. Valid zero values are retained; missing values are not filled with zero.

Chart controls¶

Hover over curves to inspect values; click legends to show or hide curves, drag a rectangle to zoom, and double-click to reset. You can export metric CSV, save chart PNG, open the experiment folder, and load historical JSONL/CSV metrics.

Files such as training_metrics.jsonl generated during training can restore recorded values. If an older log did not save a metric, loading history does not rerun validation or infer accuracy from loss.

Troubleshooting and task status¶

After a failure, switch to raw logs and inspect the first actual exception with its context, not only the final exit code. Reaching the epoch limit, early stopping, user cancellation and errors are different states.

Classic and anomaly experiments save engine.log. After an unexpected software exit, open the experiment directory from training history to read the saved log. Modern architectures usually also have results.csv, configuration and metric files; full UI raw logs are not guaranteed to survive process restarts. Use Export log to preserve the current console text.
